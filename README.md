# MCA C&I XBRL Studio — GitHub Pages package

This package is structured for GitHub Pages. It includes an iPad-friendly browser interface with:
- Save Data / Restore Saved Data
- Previous-year XML import
- Fact workbench
- Prototype pre-scrutiny
- CSV report
- XML generation

IMPORTANT: this package is a deployment-ready interface/prototype, not a substitute for the official MCA V5.1 validator. Do not file generated XML until it has passed the official MCA validation process.

MCA V3 environment configured in the UI:
https://www.mca.gov.in/V3XBRL/

## GitHub Pages
Create a repository, upload the contents of this folder, and enable Pages from the main branch/root. GitHub Pages publishes static files and requires `index.html` at the publishing root.
